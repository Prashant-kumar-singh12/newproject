About the project

A placement tool built from the student side of the table.

InternLink started as a second-year web development project at GEC Kishanganj and grew into a full platform design. This page explains what it does, why it exists, and who built it.

The problem we started with

Internship listings are everywhere. What is missing is a way to judge them. A second-year student reads "React, Node, MongoDB preferred" and has no idea whether that means apply now or learn more first.

So they apply everywhere, hear nothing, and conclude the market is closed. It usually is not — the applications were simply aimed badly.

InternLink puts the judgement back in the student's hands by scoring every listing against a real profile and showing the working.

Mission

Help every engineering student send fewer, better-aimed applications, and know exactly why each one was worth sending.

Vision

A placement season where a student from a tier-three college and one from a metro campus are read on the same evidence: what they built.

What is inside

The feature set, in the order a student meets it.

  • Profile builder — skills, availability and up to five projects with live links.
  • Ranked matches — a visible percentage with the skill gaps named.
  • Application board — five columns from applied to closed, with reminders.
  • Mentor slots — 20-minute calls with seniors who interned at the same companies.
  • Resume checker and interview sets — targeted at one posting at a time.
